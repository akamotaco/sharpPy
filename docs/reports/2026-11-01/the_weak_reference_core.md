## What changed from q4_weakref_state.md

1. **`WeakReference<T>` cannot hold the target.** The document had it in `PyWeakRef`. It has a finalizer that frees
   the handle, so a ref reachable only through a parent being finalized came back empty inside the parent's
   `__del__`. Measured: `child in parent __del__` was `[False]`, 20 of 20. `PyWeakCell` holds two `GCHandle`s, has no
   finalizer, and the guard frees them. This also replaces two `WeakReference` objects per ref with one cell per target.
2. **H1 is closed by the short handle, as proposed.** A read takes Long into a strong local, then asks Short. Short
   empty means a collection condemned the object, so the read waits for that report and answers from the verdict.
   `disagreements` is 0 in all runs.
3. **H2 is closed.** A `Cleared` guard is replaced. `Detach` with references left stays `Finalized`.
4. **`Watched` state.** An object with no `__del__` needs two reports. Added as protection against a parent and child
   being queued apart. The failure that led to it turned out to be item 1, so its need is not measured; it remains
   because the argument for it holds and it costs one extra finalizer pass per weakly referenced object.
5. A `Finalized` guard in a batch where a `__del__` ran waits one more collection, because the `__del__` may have
   kept that object.
